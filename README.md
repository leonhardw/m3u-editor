# M3U Playlist Editor

A small graphical editor for .m3u playlists

## Features
- Add songs from a folder
- Batch rename all songs in a folder (with title and artist placeholders, e.g. `%T (%A)` -> `Title (Artist).flac`)
- Rearrange songs in a playlist (with drag'n'drop support)
- Add song manually
- Absolute and relative path support

## Limitations
- Currently, only .flac files are supported (.mp3 support might come in the future)
- Only plain-text .m3u plasylists are supported
